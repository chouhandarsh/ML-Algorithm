# 🤖 ML-Algorithm

A comprehensive collection of Machine Learning algorithms, concepts, visualizations, and hands-on projects implemented using **Python**, **Scikit-learn**, **NumPy**, **Pandas**, and **Matplotlib**.

This repository serves as my personal learning journey while studying Machine Learning, where I implement algorithms, understand the underlying mathematics, and experiment with real-world datasets.

## 🚀 How to Run

Clone the repository

```bash
git clone https://github.com/chouhandarsh/ML-Algorithm.git
```

Move into the project

```bash
cd ML-Algorithm
```

Install dependencies

```bash
pip install -r requirements.txt
```

Launch Jupyter Notebook

```bash
jupyter notebook
```
